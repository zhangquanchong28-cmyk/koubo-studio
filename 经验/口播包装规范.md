# 口播包装规范（用户提供 · 已吸收进工作台）

> 来源：用户提供的《竖屏口播剪辑包装全案手册》《口播字幕样式 SOP》《BGM 配乐规范》《核心剪辑思维与流程》（2026-11）。
> 这份文件记录：规范要点 → 工作台里怎么落地 → 哪些地方没照搬、为什么。
> 风格相关的密度规则在 `styles.py`，通用原则在 `planner.py` 的系统提示词，用户个人规矩在 `我的经验.md`。

## 一、核心原则（全部采纳）
- 人声为根，可读性第一、网感第二；所有包装为人声让路。
- 克制即专业：财经/民生/知识类信任感比花哨重要；一屏一个重点。
- 前 3 秒钩子；每 10～15 秒一个注意力锚点；节奏"紧-松-紧"，不要匀速。
- 全片字体 ≤ 3 种（正文 / 重点 / 标题），高亮色 ≤ 2 种。
- 去花字、去粗描边、弱化动画是 2025–2026 财经知识口播的主流。

## 二、落地对照

| 规范 | 工作台的做法 | 说明 |

| 正文思源黑体，关键词粗体，标题粗黑 | 内置思源黑体（SIL OFL 可商用）：正文 Medium、重点词 Bold、大字/封面 Heavy | 也可在设置里填系统已装的字体名（如抖音美好体、阿里巴巴普惠体、优设标题黑） |

| 字幕比人声早 0.03～0.05 秒 | 固定提前 0.05 秒 | |
| 正文渐显 0.25 / 渐隐 0.2 | 渐显 0.15 / 渐隐 0.10 | 见"取舍 4" |
| 关键词放大 110～120%，0.15 秒 | 0.15 秒放大到 116%，回落并保持 110%；同时换粗体 + 高亮色 | |

| 调色：亮度+5 对比+3 饱和-2 锐化+8 | 滤镜「口播基础」；财经用冷调、故事用暖调 | |
| 暗角 10～15% | 「暗角」滑块（默认关） | |

| 四大风格 | 风格模板：财经、民生、知识、故事、大字报，另保留「晨晨精剪」 | AI 先判断赛道，也可手动指定 |

## 三、取舍（没有照搬的地方）
1. **字幕离底 120～150 像素：没采纳，默认约 17%（1920 高约 330 像素）。**
   抖音竖屏底部约 20% 会被标题、作者名、文案盖住，120～150 像素正好在被盖住的区域。需要更低可以在「离底部」滑块调。
2. **"禁止描边"：基本采纳，但默认不是纯阴影。**
   纯阴影在亮色、杂乱背景上可读性会下降，所以默认用"阴影 + 1～2 像素、约 45% 不透明的描边"，看上去仍是阴影风，不会有粗黑描边的廉价感。要纯阴影可以选「纯阴影」。
3. **一行 7～9 字：默认 10 字，可调 6～16。**
   7～9 字是按剪映字号 11～14 定的。我们的正文字号略大，10 字一行在 1080 宽的画面上大约占 60%。更重要的是长句会按时间拆成几条，而不是堆成两三行。
4. **渐显 0.25 秒：缩到 0.15 秒。**
   口播字幕 1～2 秒就换一条，每条都慢慢显现，前 0.25 秒字是半透明的，会显得字幕慢半拍。
5. **气口 0.3～0.5 秒：按风格区分。**
   晨晨的做法是剪得很紧，规范主张保留呼吸感，两者都对，看赛道：财经/民生/故事留得多，知识/大字报留得少。
6. **双层字幕擦除：用"底色划重点 / 下划线擦出"代替（2026-11-20 已做）**；吸入、循环动画（扫光、呼吸）暂不做。
7. **磨皮、背景虚化、人物抠像：暂不做。**
   需要人像分割模型，本地处理慢；建议拍摄时开美颜、用大光圈或背景简洁的场景。
8. **剪映曲库"可商用"曲目：用不了。**
   工作台内置的是 Mixkit 免费可商用音乐（见 assets/授权说明.txt）。要用剪映曲库，就导出剪映草稿后在剪映里换。

## 四、分赛道要点（已写进 styles.py）
- **财经/商业**：极简，重点每 3～4 句 1 个，大字 2～4 次（数字滚动优先），音效 4～8 个，配图 2～4 张，chill 或无音乐，金 + 深蓝。
- **民生/资讯**：客观中立不煽情，大字 2～3 次、不用卡片，配图可多（事件场景），红/蓝警示与政策色。
- **知识/成长**：节奏快，重点每 2～3 句 1 个，大字约每 5～7 句 1 次，配图约每 6～8 句 1 张，upbeat，橙/金。
- **故事/情感**：慢、留白，金句才做重点，音效 0～3 个，空镜配图 4～6 张，暖调，chill。
- **大字报**：开头 3 秒最狠一句 + 大字，后面回归简约，只适合钩子，全程大字报会伤信任。

## 五、2026-11-20 补充：网感字幕特效（用户反馈"字体设计不够美感、字幕太靠下"）
- 参考剪映内置文字动画目录（入场 145 / 出场 97 / 循环 93 种）挑了口播常用、克制的一批，在 `typo.py` 复刻：
  正文入场 8 种、出场 3 种、重点词 3 种（变色放大 / 底色划重点 / 下划线擦出）、大字花字 6 种、片头标题、片尾引导、分点卡片。
- 字幕默认离底 26%（原 17%），画中画配图跟着上移；字幕按 jieba 分词断句，不再把词拆开。
- 纯文字视频模式：文字居中放大 1.85 倍、粗体；背景深色渐变（按风格配色）或浅色纸张；可以只用录音做。
- 每个风格有默认动画：财经/民生=渐显+变色，知识=上滑+底色划重点，故事=逐字显影，大字报=轻微放大+底色划重点。
