口播工作台（Windows 10/11）
==========================

在你自己电脑上运行的口播自动剪辑 + 包装工具，浏览器里操作，不用登录 Claude 网页版。
流程：导入视频 → 自动转写 → Claude（Opus 5.5）出剪辑方案 → 你在表格里微调 → 一键出片。


一、安装（只需一次）
--------------------
1. 解压到一个文件夹，例如 D:\口播工作台
2. 双击 install.bat
   会自动安装 Python 3.12、FFmpeg、依赖和语音识别模型（约 2GB，10～30 分钟）
3. 双击 start.bat → 浏览器自动打开工作台（黑色窗口别关，关了工作台就停了）
4. 第一次点右上角「设置」：
   - AI 服务商选 OpenRouter，填 OpenRouter 的 API Key（sk-or- 开头）
   - 模型留空 = Claude Opus 5.5
   - 字体默认「Microsoft YaHei」（微软雅黑），可换成你装好的任意中文字体名
   Key 只保存在本机 config.json 里，不要发给别人。


二、使用
--------
1. 把口播视频拖进左上角（大文件建议在下面输入框粘贴完整路径，不复制更快）
2. 等转写完成 → 可在输入框写要求（如「财经类，压到 60 秒，节奏快」）→ 点「AI 生成方案」
3. 在表格里检查调整：
   - 取消勾选 = 删掉这句
   - 重点词：会在字幕里变色、说到时弹跳一下
   - 大字：重点词在画面中上方出现，可选三种效果：
       弹出 = 放大弹出；数字滚动 = 数字从 0 滚到目标值（只对阿拉伯数字有效，如 3000元、95%）；
       3D卡片 = 圆角色卡从侧面翻进来，停住时带一点立体倾斜
   - 推近：这一句镜头缓慢推近
   - 音效 / 颜色 / 开头钩子（把这句复制到最开头）
   - 配图：这句画面上叠一张图，人声继续。画中画（竖屏放在人物胸前、字幕上方，不挡脸）/ 全屏 / 右上角小窗
     AI 方案会自动挑适合配图的句子并写好画面描述；点「🖼 准备配图」统一找图，
     每张图下面可以「换一张」「AI画」「上传」自己的图；改了描述再点「换一张」就按新描述找
   - 顶部标题、BGM
4. 点「出片」→ 页面里直接预览，下载 成片.mp4 和 字幕.srt（srt 可导入剪映继续精修）
   所有文件也在 projects\项目编号\out\ 里。
5. 想在剪映里继续精修：点「导出剪映草稿」
   - 导出前先完全退出剪映（任务栏图标右键 → 退出）
   - 导完打开剪映，草稿列表里找「视频名_口播工作台」，没看到就重启剪映
   - 草稿里：每句一段视频（推近带关键帧）、字幕轨（重点词已变色）、大字轨、标题、音效分轨、BGM
   - 剪映打开并保存后草稿会被加密，之后只能在剪映里改；想重新生成就再点一次导出（会覆盖）
   - 字号/位置是近似换算，进剪映后可整轨统一调整
   - 找不到草稿目录：在剪映「全局设置 → 草稿位置」查看，填到工作台「设置 → 剪映草稿位置」
6. 【实验】导出到 Concat（开源剪辑器）：先装好 Concat，设置里填 concat.exe 路径（可留空自动找），
   点「导出到 Concat（实验）」，再用 Concat 打开 out\Concat\ 下的工程文件夹。
   开头钩子不会带过去；数字滚动/3D卡片在 Concat 里是普通大字/色卡。


二点五、云端剪辑（推荐：你只聊天，Claude 在云端剪）
----------------------------------------------------
1. 在 claude.ai 的 Claude Code 里开一个新会话，选这个仓库（koubo-studio）
2. 原片大于 30MB：把原片拖到「压缩代理.bat」上，得到「xxx_上传版.mp4」（太长会分成几段），发给 Claude
3. 跟 Claude 说要求，例如「按我的风格剪，压到 60 秒」。它剪好会发样片给你，你直接说哪里要改
4. 想要原片画质：让 Claude「打包方案」，下载「云端方案包.zip」
   → 本地工作台左侧「☁ 导入云端方案包」，填原片路径和方案包路径 → 点「出片」（也能导出剪映草稿）
5. 教它经验：直接说「记住，以后……」。它会写进 经验\我的经验.md，之后每次剪辑都按这个来


三、费用
--------
收费的只有两步（都走同一个 OpenRouter Key，按用量计费）：
- AI 生成方案：Opus 5.5，一条 3 分钟口播约 $0.2～0.4，页面会显示本次约多少钱
- AI 生图：默认模型约 $0.03～0.07 / 张，3 分钟视频一般 5～8 张；设置里可限制每次最多生成几张
省钱：在设置里填 Pexels / Pixabay 的免费 Key，配图会先从免费可商用图库里搜，搜不到才用 AI 画。
不填 Key 也能用：自动使用本地规则方案（只去语气词 + 简单强调），效果差一些。


四、常见问题
------------
- 识别不准：设置里把「语音识别模型」改成 large-v3（更准更慢，第一次会再下载约 3GB）
- 有 NVIDIA 显卡：设置里识别设备选 CUDA，转写快很多（需已装 CUDA）
- 字幕显示成方块：字体名填错了，换成电脑里有的中文字体，如 Microsoft YaHei、SimHei
- 端口被占用：程序会自动换一个，浏览器地址以黑色窗口里显示的为准
- 音效/BGM 授权：assets 里的音频均来自 Mixkit 免费可商用授权，见 assets\授权说明.txt


五、文件说明
------------
install.bat / setup.ps1   一键安装
start.bat                 启动工作台
server.py / ui.html       本地网页工作台
asr.py                    语音转写
planner.py                Claude 剪辑方案（内置口播方法论）
packer.py                 出片引擎（剪切、推镜头、动态字幕、数字滚动、3D卡片、音效、BGM）
jianying.py               导出剪映草稿（windows_draft.py 来自 video-shotcraft，Apache-2.0）
concat_export.py          【实验】导出到 Concat
broll.py                  配图（免费图库 + AI 生图）
assets\                   音效与 BGM
projects\                 你的项目文件
